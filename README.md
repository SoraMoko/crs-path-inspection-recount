# crs-path-inspection-recount

論文「OWASP CRSのパス検査拡張に伴う追加遮断とルール単位の原因特定」(空口・鈴木・岡崎)の再集計資料です。
匿名化した観測記録と、表3〜7の値を数え直すスクリプトを置いています。

Anonymized observations and a recount script for Tables 3–7 of our paper on URI-path inspection in OWASP CRS 4.30.0.

## 使い方

```
python recount.py
```

Python 3.9 以降で動きます。追加のパッケージは要りません。表ごとの値を JSON で出力し、`expected.json`(論文に載せた値)と一致するかを確かめます。HTTP 要求は送りません。

## data/

| ファイル | 内容 | 論文の対応箇所 |
|---|---|---|
| `main_sample.csv` | 主標本 15,561 パスの判定(PL1〜4) | 表3、表7、3.1節 |
| `removal_checks.csv` | PL3 で G31 が追加遮断した 41 パス(主標本 23、補助標本 18)について、パス検査を外したときの判定 | 表4 |
| `sites.csv` | 用途確認サイト 30 件のパスの判定(PL3) | 4.1.5項、表7 |
| `full_group.csv` | 全数群(回帰試験の正例 634 件)の判定(PL1〜4) | 表5、表7、3.1節、4.3.2項 |
| `full_group_candidates.csv` | 正例 657 件と、全数群に使ったかどうか | 3.2.3項 |
| `regression_inputs.csv` | 選別群 24 入力の予測と判定 | 4.2.1項 |
| `detailed_inputs.csv` | 詳細確認の 4 入力の判定(304 送信) | 表6 |

判定の列は HTTP 応答コードです(200 が通過、403 が遮断)。`main_sample.csv` は 1 行がパスと PL の組、`full_group.csv` は 1 行が入力と PL の組、`regression_inputs.csv` は 1 行が入力・PL・構成の組です。

構成の列:

| 列 | 構成 |
|---|---|
| `G0` `G9` `G31` | CRS 4.30.0 で、932 群のうちパスを検査するルールが 0 本、9 本、31 本 |
| `v4_29_0` | CRS 4.29.0 のルールファイルをそのまま使った構成 |
| `G31P` | G31 の 932237 から who と es を除いた構成(PR #4914) |
| `G31_cs_932237` | G31 で、パスが英数字・ハイフン・ドット・スラッシュ・下線・空白だけのとき、932237 のパス検査を省く |
| `G31_cs_932237_932238` | 同じ条件で 932237 と 932238 のパス検査を省く |
| `G31_cs_31rules` | 同じ条件で、パスを検査する 932 群の 31 ルールすべてのパス検査を省く |
| `G31_len4` | G31 で、932237 のパスへの一致を、一致した語が 4 文字以上のときだけ採点する(最初に一致した語の長さで判定する近似) |
| `G31_minus_932237` など | G31 からそのルールのパス検査だけを外した構成 |

そのほかの列:

- `cluster`:抽出元の Common Crawl 索引ブロック(番号は付け替えてあります)。ブロック単位の再標本化に使います。
- `path_rules_*`:パスに一致した 932 群のルール番号。`path_score_932_G31` は、G31 で 932 群のパス検査が加えた得点です。
- 空欄は測定していない条件です(たとえば `main_sample.csv` の `G31P` の PL1・2)。
- `sites.csv` の `path_string` は、同じパス文字列のサイトをまとめるための番号です。パスそのものではありません。
- `source_rule` と `test_id` は CRS 4.30.0 の回帰試験の番号です。`path_key` は入力を照合するためのキー(符号化後のパスの SHA-256 の先頭 16 桁)です。

`main_sample.csv` の行の順序は変えないでください。再標本化の結果が行の順序に依存します。

`v4_29_0` と `G31_cs_*`、`G31_len4` の列、および `full_group.csv` は 2026-11-17 の測定です。この測定では、応答本文だけを調べる RESPONSE-955 を全構成から外しています。

## 含めていないもの

ホスト名、URL、パスの文字列、ページ本文、WAF に送った要求は含めていません。そのため、この資料でできるのは保存した判定の再集計までで、WAF への再送信はできません。

## ファイルの確認

```
sha256sum -c SHA256SUMS
```
